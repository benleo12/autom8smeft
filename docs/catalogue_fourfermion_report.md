# Catalogue of Murphy dimension-8 four-fermion operators (classes 18 to 21)

Source: `murphy_src/sections/dim8_classes_18_v6.tex`, `dim8_classes_19_v6.tex`, `dim8_classes_20.tex`, `dim8_classes_21_v3.tex` (arXiv:2005.00059 v6), read together with `conventions_v2.tex`, `operator_classification_v5.tex` and `results_v5.tex` (summary Table `tab:summary`).

Output: `docs/catalogue_fourfermion.json` (371 entries, validated with `json.load`). The `name` and `latex` fields were extracted programmatically from the `$Q_...$ & $...$` rows of the four files (no retyping), then every row was checked by eye. The parser kept multi-column layouts (each `minipage` is a separate sub-table, all were captured) and recorded which rows sit below a `\hdashline`.

## Class numbering and conventions used

Murphy's numbering (from `tab:summary`): **18 = psi^4 H^2, 19 = psi^4 X, 20 = psi^4 H D, 21 = psi^4 D^2**. The task statement listed the four classes in a different order, the JSON follows Murphy.

Notation reminders from `conventions_v2.tex`: `X = {G^A, W^I, B}`, `psi = {l, e, q, u, d}` (l, q left-handed, e, u, d right-handed), `tau^I` Pauli matrices with `t^I = tau^I/2`, `T^A` SU(3) generators, colour indices `alpha beta gamma` (fundamental) and `A B C` (adjoint), weak indices `j k m n` / `I J K`, `Htilde_j = eps_{jk} H^{dag k}` with `eps_{12} = +1`, `Xtilde_{mu nu} = (1/2) eps_{mu nu rho sigma} X^{rho sigma}` with `eps_{0123} = +1`, `X_{L,R} = (X -/+ i Xtilde)/2`, charge-conjugation bilinears `psi_1 C psi_2 = psi_1^T C psi_2`, Hermitian derivative `i H^dag D<->_mu H = i H^dag D_mu H - i (D_mu H^dag) H` and the `tau^I` version `H^dag D<->^I_mu H`. Flavour indices p, r, s, t run over 1..3 (weak eigenstates). "Operator" in Murphy's counting = fixed flavour indices, conjugate operators counted separately. A Lagrangian term collects all flavours.

JSON field conventions:

* `hermitian` / `plus_hc_in_table`: `plus_hc_in_table` is true exactly when the sub-table header carries `+ h.c.`; `hermitian` is its negation. For Hermitian terms the flavour-summed term is self-conjugate with `Q_{prst}^dag = Q_{rpts}` (Hermitian coefficient matrix). Individual flavour components with p != r or s != t are not self-conjugate.
* `cp`: Murphy does not state CP properties anywhere in the source. The label is the CP of the operator **with a real Wilson coefficient** (for `+h.c.` operators, `C Q + C Q^dag` with real `C`). It was derived with the standard CP action on bilinears, `CP(psibar_1 Gamma psi_2) = eta_Gamma (psibar_1 Gamma psi_2)^dag` with `eta = +1` for scalar bilinears (including `psi C psi`), `eta = -1` for vector (`gamma^mu`) and tensor (`sigma^{mu nu}`) bilinears, `eta = -1` for a plain field strength X, `+1` for `Xtilde`, `-1` for `eps^{IJK}` and `f^{ABC}`, `+1` for `d^{ABC}`, derivatives and Higgs fields contribute no sign, and an explicit prefactor `i` flips the sign. `cp = even` when the product of factors is +1, `odd` when it is -1. For Hermitian terms this is the CP of the real (symmetric under `prst -> rpts`) part of the coefficient, the imaginary part has the opposite CP. For `+h.c.` operators the imaginary part of C multiplies the opposite-CP combination. No entry uses `mixed(flavor)` or `unknown`. **Important consequences** (all follow from three C-odd factors): the current-current operators `(psibar gamma^mu psi)(psibar gamma^nu psi) X_{mu nu}` are C-odd and P-even, hence **CP-odd for real coefficients, while the `Xtilde` partners are CP-even**. With an additional `eps^{IJK}` or `f^{ABC}` (C-odd invariants) the assignment flips again (`Q_{l^2q^2W}^{(5)}`, `Q_{...G}^{(5)}` even, `^{(6)}` odd) and `d^{ABC}` (C-even) keeps the plain assignment (`^{(7)}` odd, `^{(8)}` even). The two class-18 operators with `eps^{IJK}` (`Q_{l^2q^2H^2}^{(5)}`, `Q_{q^4H^2}^{(5)}`) are CP-odd for real coefficients (in the broken phase `Q_{l^2q^2H^2}^{(5)}` is `i(A - A^dag)` with `A = (nubar gamma e)(dbar gamma u)`-type). The `(LbarR)(LbarR)X` terms with two tensor bilinears (`Q_{q^2udG}^{(5),(6)}`, `Q_{q^2udW}^{(3)}`, `Q_{q^2udB}^{(3)}`, `Q_{lequX}^{(3)}`) have CP-odd real parts. All class-20 operators carry an explicit `i` that makes the real coefficient CP-even. All class-21 operators are CP-even for real coefficients. This is derived, not stated by Murphy, and should be independently checked before it drives model building.
* `n_flavor_structures_ng3`: number of real parameters at n_g = 3 with conjugate operators counted separately (the convention of `N_op` in `tab:summary`). Filled only where Murphy gives a statement (formula, "full flavour rank", "symmetric", "antisymmetric", "mixed", below-dashed-line) or where the class total forces the value uniquely (each such case is labelled "derived" in `notes`). Null for the 28 identical-field terms of classes 18 and 19 whose per-term count is neither stated nor forced (see per-class discussion).
* `field_content`: fields in order of appearance, `lbar_p` = `\bar l_p`, `Hdag`, `Htilde`, `Htilde^dag`, `Gtilde` etc., followed by the number of covariant derivatives.

## Open questions and flagged issues

1. **Colour structures of `Q_{eq^2uG}^{(1),(2)}` and `Q_{eu^2dG}^{(2),(3)}` (class 19, B-violating).** As written, `Q_{eq^2uG}^{(1)}` has the q pair in colour 3bar (antisymmetric) x `eps_{jk}` (antisymmetric) x `(q C sigma q)` (antisymmetric under exchange), and `Q_{eq^2uG}^{(2)}` has colour 6 (symmetric) x `eps_{jk}` x `(q C q)` (symmetric). Both are therefore antisymmetric in (p,r) and vanish for n_g = 1, contradicting their placement above the dashed line, the text's claim that gluon types have full flavour rank, and the n_g = 1 value of Murphy's `N_op`. The same exchange rules reproduce every other dashed-line placement in the tables (`Q_{eq^2uW,B}^{(1),(2)}`, `Q_{eu^2dB}^{(2)}`, `Q_{eu^2dD^2}^{(2)}`, `Q_{lqu^2H^2}`, dim-7 `Q_{l^2BH^2}`), so the rules themselves are not in doubt. The n_g = 1 surviving structures would be colour 6 with `(q C sigma q)` and colour 3bar (T^A on u) with `(q C q)(u C sigma e)`, i.e. the two colour tensors appear to be swapped between rows (1) and (2). Likewise `Q_{eu^2dG}^{(2)}` (3bar, `u C sigma u`) and `^{(3)}` (6, `u C u`) are symmetric in (p,r) and cannot be full rank as claimed, their antisymmetric partners (6 with `u C sigma u`, 3bar with `u C u`) are absent from the table. Murphy's formula `2 n_g^3 (21 n_g + 1)` is reproduced only if these four rows are assigned the full-rank value 162, which is what the JSON records (with a WARNING in `notes`). Resolution needed before implementing the B-violating class-19 gluon operators.

2. **Probable typos in the source tables** (recorded in `notes`): `Q_{lqd^2H^2}` is written `(l_p^j q_r^{m alpha})` and `Q_{eq^2dH^2}` is written `(e_p d_r^alpha)`, both without the `C` matrix that every other charge-conjugation bilinear carries. `Q_{leq^2HD}^{(6)}` has `gamma^nu` in the current while the derivative is `D_mu` (should be `gamma^mu`). `Q_{qud^2HD}^{(4)}` has its closing bracket outside the math environment (cosmetic). The caption of `tab:smeft8class_18` says "class-9" twice where class-18 is meant, and the psi^4 D^2 paragraph of the classification section refers to "class 19" where class 21 is meant (stale numbering).

3. **`(eps tau^I)` versus `(tau^I eps)`.** The tables use `(eps tau^I)_{jk}` in B-violating entries (`Q_{lqudH^2}^{(2)}`, `Q_{lq^3H^2}^{(2),(3)}`, `Q_{lqudW}`, `Q_{eq^2uW}`, `Q_{lq^3W}`) and `(tau^I eps)_{jk}` in `(LbarR)(LbarR)` entries (`Q_{q^2udH^2}^{(2),(4)}`, `Q_{lequH^2}^{(2),(4)}`, `Q_{q^2udW}`, `Q_{lequW}`), while the text's redundancy relations for `Q_{lq^3H^2}` and `Q_{lq^3W}^{(2a,2b)}` use `(tau^I eps)`. Since `(eps tau^I) = -(tau^I)^T eps`, the two matrices differ by I-dependent signs (equal to `-(tau^I eps)` for I = 1, 3 and `+(tau^2 eps)` for I = 2) and, summed against `W^I` or `(H^dag tau^I H)`, give different (though equally valid) operators. The JSON keeps each row exactly as written. Whether the text relations apply to the table operators with the opposite ordering is not settled.

4. **Index-height inconsistencies** to be interpreted rather than transcribed: `Htilde^k Htilde^n` in `Q_{lqu^2H^2}` (Murphy defines `Htilde_j` with a lower index), `H^{n dag}` with an upper index contracted by `eps_{jn}` in `Q_{lq^2uHD}^{(1),(2),(3)}` (elsewhere `H^dag_j`). The intended pairings are stated in `notes`.

5. **Fermionic Hermitian derivative.** `psibar gamma^mu D<->^nu psi`, `psibar D<-> psi`, and in particular `D<->^{I nu}` in `Q_{q^4D^2}^{(4)}` and `Q_{l^2q^2D^2}^{(4)}` are never defined in the conventions (only the Higgs versions are). Assumed by analogy: `psibar Gamma D<->_nu psi = psibar Gamma D_nu psi - (D_nu psibar) Gamma psi` and `D<->^I` with a `tau^I` inserted.

6. **Per-term flavour counts not determined for identical-field terms of classes 18 and 19.** Class 18(B): with full rank for all distinct-field terms, the 14 identical-field terms must sum to 900 real parameters at n_g = 3. The natural assignments (45 for `Q_ll`-like terms, 90 for the symmetric bi-Yukawa terms, 36 for `e^4 H^2`) leave 27 for `Q_{q^4H^2}^{(5)}`, not the 36 one would read off the `(S x A) + (A x S)` representation quoted in eq. (Qflav), and Murphy's `N_op` contains an `n_g^3` term that a pure `(S x A)+(A x S)` count cannot produce. Class 19(B): the total requires three of the 14 identical-current `X = G, W` terms (`Q_{l^4W}`, `Q_{q^4G}`, `Q_{q^4W}`, `Q_{u^4G}`, `Q_{d^4G}`) to have `(1/2) n_g^2 (n_g^2 + 1) = 45` instead of 81, which three is not stated. These 28 entries carry `null`.

7. **Counting convention of the text formulas.** Murphy's `(2/3) n_g^2 (2 n_g^2 + 1)` for `Q_{lq^3H^2}^{(1,2)}` explicitly includes h.c., while `(1/3) n_g^2 (n_g^2 - 1)` for the mixed-symmetry terms and `n_g^3 (n_g - 1)` for the three new types are quoted without saying. The class total is reproduced exactly only with 48 (= 2 x 24) for `Q_{lq^3H^2}^{(3)}` and 54 (h.c. included) for each of `Q_{lqu^2H^2}`, `Q_{lqd^2H^2}`, `Q_{eq^2dH^2}`, so those are the values recorded.

8. `N_type` for class 19(B-slash) is given as 4 in `tab:summary` although, counting field strengths separately as is done for the B-preserving types (40 + 5), there are 11 B-violating types (`lqudG, lqudW, lqudB, eq^2uG, eq^2uW, eq^2uB, lq^3G, lq^3W, lq^3B, eu^2dG, eu^2dB`). Bookkeeping only, no effect on the operator list.

9. `Q_{q^4H^2}^{(4)}` is defined in the text as the combination `Q^{(1)}_{prst} + Q^{(2)}_{prst} + Q^{(2)}_{stpr} + Q^{(3)}_{prst}` for flavour bookkeeping and is not a separate basis operator (consistent with `N_term = 75 + 1`). It is not in the JSON. Likewise `Q_{l^4H^2}^{(3),(4),(5)}` and `Q_{lq^3H^2}^{(1a)...(4b)}` and `Q_{lq^3W}^{(2a),(2b)}` are redundant operators discussed in the text only.

10. The CP labels are derived (see conventions above), Murphy gives none. The counter-intuitive assignment (plain `J J X` CP-odd, `J J Xtilde` CP-even for real coefficients) should be cross-checked independently before it is used to select a CP-even subset.
