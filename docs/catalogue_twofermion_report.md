# Murphy dimension-8 two-fermion operator catalogue (classes 9 to 17)
Source: arXiv:2005.00059 v6 LaTeX (murphy_src/sections/dim8_classes_9.tex, dim8_classes_10_11_12_13_v2.tex, dim8_classes_14_v2.tex, dim8_classes_15.tex, dim8_classes_16_17.tex), with conventions from conventions_v2.tex, class numbering and text from operator_classification_v5.tex, and the summary table (tab:summary) from results_v5.tex.
Output JSON: ${DIM8_ROOT:-.}/docs/catalogue_twofermion.json (274 entries, one per table row; LaTeX copied verbatim from the source and verified by string search).
Two extra keys beyond the requested schema are present in every entry: `table_header` (the bold class header of the sub-table the row came from) and `self_conjugacy_as_written` (one of hermitian, anti-hermitian, non-hermitian). The requested key `hermitian` is true for both hermitian and anti-hermitian-as-written rows, because Murphy counts both as single terms without a separate Hermitian conjugate. See the Hermiticity section below.
## Conventions used when filling the fields
Class numbering follows the enumerate list in operator_classification_v5.tex and tab:summary: 9 psi^2X^2H, 10 psi^2XH^3, 11 psi^2H^2D^3, 12 psi^2H^5, 13 psi^2H^4D, 14 psi^2X^2D, 15 psi^2XH^2D, 16 psi^2XHD^2, 17 psi^2H^3D^2.
Flavor indices: every two-fermion operator carries p (first, barred fermion) and r (second fermion). Murphy: two-fermion terms always contain n_g^2 operators. `n_flavor_structures_ng3` is derived from that statement and the N_op column of tab:summary: 9 real parameters (Hermitian n_g x n_g coefficient matrix) for a self-conjugate term, 18 for a term with a distinct Hermitian conjugate (complex n_g x n_g matrix). Murphy does not give per-row numbers.
The N_term column of tab:summary counts a non-self-conjugate operator and its Hermitian conjugate as two terms. For every class the extracted row count reproduces N_term with that rule (see the table below).
`cp` is NOT stated by Murphy. It was derived here for the flavor-diagonal operator with a real coefficient (for Hermitian coefficient matrices: the real symmetric part; the imaginary antisymmetric part has the opposite CP) using a C and P block analysis. Rule: write CP(Q) = eta Q^dagger with eta the product of block signs: vector bilinear (with or without derivatives, including psibar gamma^mu D<->^nu psi) -1, tensor bilinear sigma^{mu nu} (with or without derivatives) -1, scalar bilinear (with or without derivatives) +1, each field strength -1, each dual field strength +1 (the extra -1 from epsilon_{mu nu rho sigma}), each epsilon^{IJK} or f^{ABC} contraction -1 (because (tau^I)^T = eta_I tau^I with eta_1 eta_2 eta_3 = -1, same for f^{ABC}), d^{ABC} and delta contractions +1, every Higgs covariant (H, Htilde, H^dag H, H^dag tau^I H, D(H^dag H), H^dag D<-> H, D_mu H^dag D_nu H, ...) +1, and each explicit factor of i -1. Then: a Hermitian-as-written operator has CP parity eta; an anti-Hermitian-as-written operator (physical operator i Q) has CP parity -eta; a non-Hermitian operator with coefficient C has CP parity eta for Re C and -eta for Im C. Standard checks pass: dimension-6 Q_He (even), Q_eB real part (even), Q_W (even), Q_HWtilde (odd).
Consequences that differ from the naive 'dual tensor present <=> CP-odd' rule, all flagged in the `notes` field: (a) class 9 sigma^{mu nu} operators with two different field strengths and no epsilon^{IJK}/f^{ABC} (Q_{quGWH}^{(3)}, Q_{quGBH}^{(3)}, Q_{quWBH}^{(3)}, Q_{leWBH}^{(3)}, Q_{qdGWH}^{(3)}, Q_{qdGBH}^{(3)}, Q_{qdWBH}^{(3)}) are CP-odd for a real coefficient; (b) class 13 Q_{l^2H^4D}^{(3)} and Q_{q^2H^4D}^{(3)} (i epsilon^{IJK} ... H^dag D<->^J H ...) are CP-odd; (c) class 14: the f^{ABC}/epsilon^{IJK} operators without dual, Q^{(2)}_{psi^2G^2D} and Q^{(2)}_{psi^2W^2D}, are CP-odd, while the dual-containing Q^{(4),(5)} of the G^2 and W^2 types are CP-even; for the mixed types (GW, GB, WB) the naive rule holds ((1),(2) even, (3),(4) odd); (d) class 15: for every type the H^dag D<-> H operators have the opposite assignment to the D(H^dag H) ones: (1) even, (2) odd, (3) odd, (4) even, and likewise (5) even, (6) odd, (7) odd, (8) even; for the epsilon^{IJK} operators (9) odd, (10) even, (11) even, (12) odd; (e) class 16: all 24 operators are CP-even for a real coefficient, including the Q^{(2)} ones that contain a dual field strength (scalar bilinear with derivative times dual); (f) class 17: Q^{(3)}, Q^{(4)}, Q^{(6)} (sigma^{mu nu} contracted with D_mu H^dag D_nu H or H^dag D_mu H D_nu H) are CP-odd for a real coefficient. These derived assignments should be checked independently before being relied on.
`baryon_violating` is false for every entry: all two-fermion classes conserve baryon and lepton number (every bilinear is psibar psi with the SM hypercharges balanced by Higgs fields). No CP-odd-only or n_g=1-vanishing rows exist in these classes; every row is present for one generation.
## Hermiticity as written (important for implementation)
Non-Hermitian rows (distinct h.c. required, marked by the table header '+h.c.' or by '+h.c.' after the name): all of classes 9, 10, 12, 16, 17 and the ud rows of classes 11, 13, 15 (Q_{udH^2D^3}, Q_{udH^4D}, Q_{udGH^2}^{(1,2)}, Q_{udWH^2}^{(1,2)}, Q_{udBH^2}^{(1,2)}).
Hermitian as written: class 13 (after restoring the missing bars), class 14 rows that begin with an explicit i (the (mu,nu)-symmetric tensor structures), class 15 rows built on D^mu(H^dag H), D^mu(H^dag tau^I H).
Anti-Hermitian as written (Q_pr^dagger = -Q_rp), 62 rows: class 14 rows without a leading i, namely Q^{(2)}_{q^2G^2D}, Q^{(5)}_{q^2G^2D}, Q^{(2)}_{q^2W^2D}, Q^{(4)}_{q^2W^2D}, Q^{(1),(3)}_{q^2GWD}, Q^{(1),(3)}_{q^2GBD}, Q^{(1),(3)}_{q^2WBD}, Q^{(2),(5)}_{u^2G^2D}, Q^{(1),(3)}_{u^2GBD}, Q^{(2),(5)}_{d^2G^2D}, Q^{(1),(3)}_{d^2GBD}, Q^{(2),(4)}_{l^2W^2D}, Q^{(1),(3)}_{l^2WBD} (22 rows), and every class 15 row containing H^dag D<->^mu H or H^dag D<->^{I mu} H with no i, i.e. superscripts (3),(4),(7),(8),(11),(12) of each type (40 rows). Murphy counts each as one term with n_g^2 operators; a Hermitian Lagrangian needs C_rp = -C_pr^* for these, or equivalently the operator must be multiplied by i and used with a Hermitian coefficient matrix. Murphy himself includes the i in the analogous class 13 and dimension-6 operators, so this is a convention inconsistency in the source, not a counting error.
Class 11 (14 non-ud rows): written with a single derivative on the unbarred fermion and D_(mu D_nu) on H^dag or H; the Hermitian conjugate is a different-looking operator (derivative on the barred fermion, derivatives on the other Higgs). Murphy treats each as one Hermitian term (16 n_g^2 operators in the class). Self-conjugacy holds only modulo IBP/EOM, which an implementation must either verify or sidestep by adding (Q + Q^dagger)/2 explicitly.
## Source typos and label issues found
1. Class 11 label Q_{q^2H^2D^2}^{(4)} (line 63 of dim8_classes_10_11_12_13_v2.tex) should be Q_{q^2H^2D^3}^{(4)}. The JSON keeps the source name and flags it in notes.
2. Class 13: every operator is written with the first fermion unbarred, e.g. (l_p gamma^mu l_r); it must be (bar l_p gamma^mu l_r). Flagged in notes; LaTeX kept verbatim.
3. Class 15 ud rows are labelled Q_{udGH^2}, Q_{udWH^2}, Q_{udBH^2} (no D in the type label) in both table and caption; by Murphy's own naming scheme they should be Q_{udGH^2D} etc. Flagged in notes.
4. Captions of tab:smeft8class_14le_15RR and tab:smeft8class_15LL describe class 15 as '(bar R R)X^2H' and '(bar L L)X^2H'; the content is XH^2D.
5. operator_classification_v5.tex, class psi^2XHD^2 discussion: 'to find the class 17 operators with field content l, e, H, B_R' should read class 16 (class 17 is psi^2H^3D^2 in the same enumeration and in tab:summary).
6. operator_classification_v5.tex, class 9 text: '24 terms ... whereas 48 terms come from (X^2)(psi^2 H)' sums to 72, but tab:summary says 96 = 2 x 48 rows. Counting rows: 12 sigma^{mu nu} rows (x2 with h.c. = 24) and 36 scalar-bilinear rows (x2 = 72); the text's 48 appears to be a leftover.
7. operator_classification_v5.tex eq. (Q3): 'i Q_{q^2H^4D}^{(3)} = -Q^{(2l)} + Q^{(2r)}'. Using Murphy's eq. (fierz_ep) directly, Q^{(2l)} - Q^{(2r)} = +/- epsilon^{IJK}(bar q gamma^mu tau^I q)(H^dag tau^J H) D_mu(H^dag tau^K H) = +/- Q^{(4)}, not Q^{(3)}; and Q^{(3)} is Hermitian as written, so i Q^{(3)} is anti-Hermitian while the right-hand side is Hermitian. The table basis {Q^{(1)},Q^{(2)},Q^{(3)},Q^{(4)}} still has the stated four terms, so only the explanatory equation seems wrong. Open question; the sign depends on the row/column convention for (tau^I)_j^k.
8. Table ordering quirk: Q_{quWBH}^{(3)} appears before Q_{quWBH}^{(1),(2)} in tab:smeft8class_9. Rows were kept in source order.
9. Class 17: Q_{quH^3D^2}^{(5),(6)} use (D_mu H^dag H) while the le and qd analogues use (H^dag D_mu H). This is deliberate (the two like-type fields are H^dag and Htilde for the qu case), not a typo.

## Open questions for the orchestrator
1. Phase convention for the 62 anti-Hermitian-as-written rows (class 14 without leading i, class 15 H^dag D<-> H rows): multiply by i and use Hermitian coefficients, or keep Murphy's form with anti-Hermitian coefficients? Either is consistent with Murphy's counting; the choice affects how Wilson coefficients map onto other bases and codes.
2. Class 11 self-conjugacy modulo IBP/EOM has not been verified here; recommend implementing (Q + Q^dagger)/2 or checking explicitly in FeynRules.
3. Murphy eq. (Q3) versus the table definitions of Q^{(3)}, Q^{(4)} in class 13 (see typo item 7). Affects only the interpretation, not the basis, but should be resolved before quoting relations between the q^2H^4D operators.
4. The derived CP assignments (especially the non-naive ones listed above) are my block-rule derivation and are not in the source; they should be verified independently (for example numerically with the UFO) before being used to select a CP-even subset.
5. The ud rows of class 15 are named Q_{udXH^2} in the source; decide whether to adopt the corrected Q_{udXH^2D} label in the model.
