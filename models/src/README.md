# Model source

The FeynRules source the UFOs in `models/` are built from. Everything here is generated or
maintained by the code in `gen/` and `validate/`; nothing is typed by hand.

| file | what it is |
|---|---|
| `dim8_generated.fr` | the master dimension-eight Lagrangian: one `Block` per operator (`L8opNNN`), one named coefficient per operator (`c8...`), flavour universal, emitted by `gen/emit_fr.py` from the operator encoding `gen/operators.py`. `docs/block_index.json` maps every block to its operator label and coefficient. |
| `base.fr` | the Standard Model base (FeynRules SM template, unitary gauge, Goldstones removed). `models/dim8_plain` is `base.fr + dim8_generated.fr`. |
| `base_inputscheme.fr` | the base with the {alpha, M_Z, G_F} input scheme and canonical normalisation through 1/Lambda^4, emitted by `gen/input_scheme.py` from `gen/input_scheme_formulae.json`. `models/dim8_is` is `base_inputscheme.fr + dim8_generated.fr` with the Lambda^-8 truncation (`DIM8_TRUNCATE=1`). |
| `base_inputscheme_mw.fr` | the same in the {M_W, M_Z, G_F} scheme (`gen/input_scheme_formulae_mw.json`). |
| `base_fg.fr` | the base in Feynman gauge, used only for MadGraph's `check gauge`. |

## Conventions

The covariant derivative is `D_mu = d_mu + i g A_mu`, Murphy's convention, set by
`FR$DSign = -1` in the base files. This is the opposite of the FeynRules default. When comparing
with a model built on the default convention the two are related by `A -> -A`, under which the
Standard Model is invariant and every field strength changes sign, so a coefficient here equals
`(-1)^{n_F}` times the coefficient of the same operator there, with `n_F` the number of field
strengths in the operator. Covariant-derivative operators carry no sign.

## From source to UFO

`validate/fr_worker.wls` evaluates one block at a time (`ExpandIndices`, `FeynmanRules`,
`CheckHermiticity`) and caches the vertex list, and `validate/fr_writeufo.wls` merges the caches
for a chosen block list and writes the UFO. Both are headless `wolframscript` programs that load
`tests/fr_env/fr_headless_init.m` (the runtime fixes FeynRules 2.3 needs on Mathematica 14) and
read the base file and `gen.fr` from `tests/gen_smoke` under `DIM8_ROOT`. The base files are
there too, and `./dim8 build` writes `gen.fr` there from `gen/operators.py` before it starts the
workers, so this directory is the readable copy and `tests/gen_smoke` the working one. The base
is chosen with `DIM8_BASE` (default `base.fr`), the cache directory with `DIM8_VDIR`. The usage
lines at the top of each script give the arguments.

## Not shipped

The dimension-six sector of `models/dim68_is` uses SMEFTsim's operator definitions on this base;
obtain SMEFTsim from its authors and run `gen/make_dim6.py` (see `docs/DIM6.md`). The vertex
caches are build artifacts and are regenerated by `fr_worker.wls`.
